# Crime Reporting System — MERN

## Academic prototype
Features:
- User registration and login
- Crime complaint reporting
- Anonymous complaints
- Complaint tracking
- SOS location alerts
- Admin dashboard

## 1. Backend
Open a terminal in `backend`:
npm install
Create `.env` from `.env.example`
Add your MongoDB Atlas connection string.
Run:
npm start

## 2. Frontend
Open a second terminal in `frontend`:
npm install
npm start

The frontend opens at http://localhost:3000
The backend runs at http://localhost:5000

## Admin
Register a normal account first, then change that user's `role` to `admin` in MongoDB Atlas.

## Important
This is an academic prototype. SOS does not contact real emergency services or police.
